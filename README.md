# Vela distribution metrics archive

Public aggregate GitHub statistics; no Vela runtime telemetry.

- data/summary.json: dashboard-friendly trends and release breakdown.
- data/latest.json: latest collection status and counts.
- data/traffic-daily.json: persistent per-day clone/view history.
- data/referrers.json and data/popular-paths.json: latest rolling top-ten lists.
- data/discovery-snapshots/: archived overlapping rolling-window rankings.
- data/release-snapshots/: daily Release asset counters.
- data/release-asset-history.json: observed maxima, including removed assets.

Gaps are unknown, not zero. Daily unique counts cannot be added together.
Observed maxima are not exact all-time downloads.
