# The Vela icon theme

Windows 11 style, generated by one script (kept out of the repository) from:

- Fluent System Icons (Microsoft, MIT, `LICENSE-fluentui-system-icons`): the symbolic glyphs,
  as `currentColor` drawings; the dark theme paints them in the dark text color (`icons/CMakeLists.txt`).
- Vela's own drawings: the yellow folders (the special folders carry a Fluent glyph) and their open versions.
- `actions/start-here.svg`: the Start button's four panes, from lowell's `start.next.svg` (source and license not recorded yet).
- Reversal icon theme (GPL-3.0, github.com/yeyushengfan258/Reversal-icon-theme): the network, volume and
  microphone status drawings.
- Win11 icon theme (GPL-3.0, github.com/yeyushengfan258/Win11-icon-theme): the wired network drawing
  (monitor with its cable) and the Steam icons.

- Windows 11 icons (Microsoft, not under this project's GPL and not MIT): `NNxNN/places/*.png` and part of `scalable/actions`, extracted from an installed Windows 11 (imageres.dll, shell32.dll, Segoe Fluent Icons, File Explorer's assets). No license to redistribute them has been recorded.

Apps, files, drives and the rest come from the themes it inherits (Reversal, Fluent, Breeze, hicolor) when installed.
