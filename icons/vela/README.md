# The Vela icon theme

Windows 11 style. Commands and status are glyphs; everything else comes from the Win11 icon theme
(inherited: colored folders, drives, trash, file types, apps and what the File Explorer shows).
Generated by one script (kept out of the repository) from:

- Fluent System Icons (Microsoft, MIT, `LICENSE-fluentui-system-icons`): the glyphs of commands and status,
  as `currentColor` drawings; the dark theme paints them in the dark text color (`icons/CMakeLists.txt`).
- Win11 icon theme (GPL-3.0, github.com/yeyushengfan258/Win11-icon-theme): the network, volume and
  microphone status drawings (light and dark), the tray's Steam icon.

The theme inherits `Win11` (`Win11-dark` in the dark mode) when it is installed, then Reversal, Fluent,
Breeze and hicolor.
