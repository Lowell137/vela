# Fluent System Icons, the pieces Vela uses

24 px "regular" and "filled" SVGs from https://github.com/microsoft/fluentui-system-icons
(MIT, see LICENSE), downloaded unchanged (`assets/<Name>/SVG/ic_fluent_<name>_24_<style>.svg`).
`scripts/icon-style-sheet.py` maps them to freedesktop names in `icons/vela/scalable`.
The WiFi icons have no separate filled drawing: regular and filled are identical.
